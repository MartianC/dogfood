## TDesign 与项目适配层映射

| 设计项 | TDesign 建议 | 项目实现映射 / 约束 |
| --- | --- | --- |
| 底部 Dock | `TabBar` | 必须直接复用 TDesign 原生 `TabBar` 的 `theme=tag`、`shape=round` 变体；图标在上、文字在下。文字内容、颜色和图标可通过组件公开属性或实例文字覆盖调整，但不得改变组件布局、尺寸、位置或变体 |
| 主操作、次级操作 | `Button` | 使用 `components/ui/*` 的按钮封装，不在页面直接写第三方标签 |
| 搜索食材 | `Search` | 通过 `components/vendor/*` 或 `components/ui/*` 提供统一事件与样式 |
| 基础信息字段 | `Input`、`Textarea`、`Cell` | 使用 `ui-field`；保留错误文案与保存中状态 |
| 食材行 | `Cell` | 业务行组件管理编辑、删除和合并提示，不把数据规则塞入页面样式 |
| 克重 | `Input` + `Stepper` | 输入必须校验为大于 0 的数值；重复食材合并克重 |
| 克重弹层、营养汇总 | `Popup`（bottom）或 `Drawer` | 固定底部并保留安全区；点击展开 / 收起为必备交互 |
| 营养指标 | `Cell` + 业务 `NutritionMetric` | 同时显示数值、目标或“暂无参考值”、文字状态；不可只靠颜色 |
| 空状态 | `Empty` | 使用 `ui-empty`，不替换为静态说明文字 |
| 加载 | `Loading`、`Skeleton` | 优先骨架屏，避免整页空白和布局跳动 |
| 删除确认 | `Dialog` | 默认焦点为“取消”；删除为二次确认的高风险操作 |
| 轻量反馈 | `Toast` | 保存失败需保留当前编辑内容并提供“重试保存” |

## 状态规则与实现说明

- 营养状态使用“偏低 / 适中 / 偏高”等文字加色彩表达；颜色不能是唯一信号。
- 没有可靠目标时显示“暂无参考值”，不展示误导性的比例或健康结论。
- 营养文案只做配方参考说明：`营养数据仅供配方参考，如有健康问题请咨询兽医`。
- 抽屉收起时不遮挡新增食材、列表末项和底部主操作；展开后应始终可关闭并回到食材编辑。
- 保存失败、网络重试和重复食材合并均需保留用户输入，避免静默丢失内容。
- 页面不可直接耦合 TDesign 的第三方标签；统一由 `components/vendor/*` 或 `components/ui/*` 适配。
