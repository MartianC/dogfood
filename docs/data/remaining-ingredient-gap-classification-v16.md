## 建议处理顺序

1. CFCT/USDA 精确来源候选：执行唯一身份、状态和营养完整度门禁。
2. 基础食材身份候选：优先高频单一物种和部位，建立受控来源决定。
3. 相对稳定加工品：只使用同加工状态的通用来源。
4. 形态换算：建立干湿、生熟和可食部换算后再计入营养覆盖。
5. 上位词、省略词和组合词：只接受显式约定或结构化拆分。
6. 配方不稳定加工品、品牌品和低频噪声最后处理。

完整逐项结果见同版本 JSON。
