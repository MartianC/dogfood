# 标准食材只发布一个烹调基准营养来源

标准食材目录不再同时发布同一食材的生熟、带骨、带皮等多个营养形态。每个标准食材概念由确定性规则从候选营养档案中选择唯一烹调基准，优先生鲜、去骨、去皮、无调味且可直接烹调的记录；没有理想候选时按受控顺序降级并记录原因。历史 `variant_id` 作为兼容键保留，但不再表示产品中可并存的多形态选项，以换取更稳定的食材身份、菜谱映射和营养计算口径。

新概念也由确定性发现规则生成：菜谱写法只能在清洗后唯一命中来源中文名、来源分类一致且英文描述身份相容时进入候选。无法自动证明身份一致的项保持隔离，不设置“必须由人处理后才能继续”的发布前提。由此，流水线可以无人值守重复运行，但覆盖率受可信来源名称的实际覆盖限制。
