# AnyPal UIA

Optional home for recordings/results. Cases are `*.apuia` files (JavaScript
content) discovered **anywhere** in the workspace — you may keep them here
or next to the code under test. See skill `create-anypal-uia-test`.

- `.recordings/` — recording session packages (events + screenshots). gitignored.
- `.results/`   — run reports and failure screenshots. gitignored.
