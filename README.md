# 爪饭

爪饭是一款微信小程序，帮助养狗家庭从已经决定的人饭菜单中挑选可共用的基础食材，为狗狗单独准备一顿饭，查看本餐评估并留下记录。

“和狗狗一起吃”不是把已经调味的人饭分给狗狗。狗饭需要单独称量、单独烹饪，不添加人饭中的盐、油、酱汁和其他调味。

## 可以做什么

- 创建和管理多只狗狗的档案。
- 从已发布的人饭菜谱中选择一道或多道菜，查看原料及其与目标狗狗的适用状态。
- 手动填写狗饭食材和克重，查看本餐能量与营养密度评估；需要调整时，可以主动预览并确认按能量目标等比例调整整餐。
- 暂存并继续未完成的本餐，保存后按日期查看记录和当时的评估快照。

## 使用边界

- 产品评估的是单独一餐，不会规划或推荐人饭，也不会自动决定狗饭食材的首次克重或比例。
- 保存表示记录了这一餐，不代表本餐营养完整，也不代表适合长期重复喂养。
- 若家庭自制餐长期占主要饮食，请咨询兽医或宠物营养专业人士。

## 本地运行

需要安装 Node.js、npm 和微信开发者工具。项目使用微信小程序原生框架与 CloudBase；访问登录和云端数据还需要有权限的微信小程序及 CloudBase 开发环境。

1. 在仓库根目录安装依赖：

   ```sh
   npm install
   ```

2. 使用微信开发者工具打开仓库根目录，并按需配置小程序账号与 CloudBase 开发环境。相关项目配置位于 `project.config.json` 和 `config/env.js`。
3. 在开发者工具中编译运行或预览小程序。云函数和云端数据资源需按项目环境单独配置。

常用本地检查：

```sh
npm test
npm run check:ui
npm run check:project-navigation
npm run check:main-package
npm run check:subpackage-services
```

## 项目结构

| 路径 | 内容 |
| --- | --- |
| `pages/` | 小程序主包页面 |
| `subpackages/` | 狗狗档案、共享本餐等分包页面与服务 |
| `services/` | 登录、档案、记录和首页等业务服务 |
| `cloudfunctions/` | CloudBase 云函数 |
| `components/` | 小程序组件 |
| `docs/` | 产品、架构、数据和界面设计资料 |
| `tests/` | Node.js 自动化测试 |
