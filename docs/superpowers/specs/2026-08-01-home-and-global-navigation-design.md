## 1. 范围与设计裁决

本设计只完成路线图 `D1.1`，不修改小程序页面、导航配置、业务服务或云环境。

- 首页围绕“今天接下来做什么”组织为日期与标题、唯一主任务、今天摘要和最近一顿；
- 游客、无档案、有草稿、今天无记录、今天有记录和数据失败均使用真实现有能力，不加入体重、护理或医疗占位；
- 底部导航保留“首页、记录、狗狗、我的”四个真实目的地；
- 中央“记一顿”是独立动作，不拥有 Tab 选中态，不改变当前选中的目的地；
- 以 375pt 为主要画布，同时交付 320pt 窄屏、390pt 多狗长文案压力状态；
- 页面沿用浅绿背景、白色表面、深绿主操作、暖色错误、低噪声阴影和 Noto Sans SC。

## 4. 首页状态合同

| 状态 | 唯一主任务 | 今天摘要 | 最近一顿 |
| --- | --- | --- | --- |
| 游客 | 登录并继续；保留原记餐意图 | 说明登录后可见内容 | 不请求或伪造历史 |
| 已登录、无档案 | 新增狗狗档案 | 说明保存后返回原意图 | 允许展示真实既有快照 |
| 有草稿 | 查看草稿，由用户决定下一步 | 标明狗狗和草稿更新时间 | 展示最近真实快照 |
| 今天无记录 | 记一顿 | 明确今天尚无保存记录 | 展示最近真实快照 |
| 今天有记录 | 查看今天的本餐记录 | 标明狗狗、数量和快照语义 | 展示今天最近一顿 |
| 数据失败 | 记一顿仍可用 | 暖色错误块与稍后重试说明 | 失败时不展示不可靠内容 |

多狗状态必须逐只标明对象和状态，不制造“当前狗”。主任务最多一个；今天摘要和最近一顿是次级信息，不与主操作竞争。

## 5. 全局导航规格

### 5.1 几何与安全区

| 项目 | 375/390pt | 320pt |
| --- | --- | --- |
| 导航外框 | `343 × 64pt`，水平居中 | `288 × 64pt`，左右各 16pt |
| 导航底部 | 距画板底部 28pt | 距画板底部 28pt |
| 中央 Fab | TDesign `Fab`，`48 × 48pt` | 同左 |
| 中央点击目标 | 规格按 `56 × 56pt` 预留 | 同左 |
| 图标 | TDesign Icon，20pt | 同左 |
| 标签 | 11pt，Noto Sans SC | 同左 |

页面滚动内容必须为导航、中央 Fab 和安全区预留底部空间；最后一项不能被固定层遮挡。后续真机实现仍需读取 `env(safe-area-inset-bottom)`，28pt 是本轮基准画板的验收值，不是写死的设备常量。

### 5.2 状态与语义

- 默认状态：当前目的地使用 `--df-color-primary` 前景和 `--df-color-primary-soft` 背景；其他目的地使用 `--df-color-muted`；
- 中央默认：`--df-color-primary` 背景、白色加号；
- 中央按下：只切换为 `--df-color-primary-pressed`，当前 Tab 仍保持原选中态；
- 无障碍名称：`记一顿`；不得朗读为“第五个标签页”；
- 触发结果：调用 `sharedMealEntryService.startSharedMeal()`，不在 TabBar 内复制登录、档案、资格或草稿判断；
- 取消、返回或遮罩关闭：不改变原选中 Tab，不清除草稿。

## 6. Token 与组件映射

| Figma 语义 | 工程映射 | 本轮用法 |
| --- | --- | --- |
| 页面背景 | `--df-color-bg` | 所有首页画板 |
| 表面 / 弱表面 | `--df-color-surface` / `--df-color-surface-muted` | 主任务、摘要和最近一顿 |
| 主 / 次 / 弱文本 | `--df-color-text` / `--df-color-text-secondary` / `--df-color-muted` | 页面、卡片和导航层级 |
| 主操作 / 按下 | `--df-color-primary` / `--df-color-primary-pressed` | 主按钮与中央 Fab |
| 错误 / 弱错误 | `--df-color-warning` / `--df-color-warning-soft` | 数据失败摘要 |
| 主任务、摘要、最近一顿 | `ui-card` 组合 | 不新增 Card 变体 |
| 页面主动作 | `ui-button` | 44pt 高；长文案按内容宽度居中 |
| 错误说明 | `ui-notice` 的 warning 语义 | 不阻断统一入口 |
| 空内容 | `ui-empty` 或 `ui-card + ui-button` 业务组合 | 不新增第二套空态系统 |
| 四个目的地图标 | TDesign Icon | 首页、记录、狗狗、我的 |
| 中央动作 | TDesign Fab | `size=large/theme=primary/shape=circle/text=false` |
| 工程底部导航 | `custom-tab-bar` 包装 TDesign TabBar/TabBarItem | 页面不得直接使用 `<t-*>` |

现有 Figma“食谱”语义变量早于当前 `--df-*`，主色、页面背景和正文色存在历史差异。本轮不修改旧变量，避免影响已评审页面；新画板按当前工程 token 映射实例颜色，并将差异记录为交接约束。

Figma MCP 当前未提供 `PingFang SC`，不能跨页面重新实例化携带该字体的 TDesign TabBar。设计稿因此以 TDesign 图标组件和 Fab 实例组合出与 `theme=tag/shape=round` 相同的导航外观，自由中文使用 Noto Sans SC。工程实现仍必须通过 `custom-tab-bar` 复用 TDesign TabBar/TabBarItem，不得据此改为页面自绘第三方组件。
