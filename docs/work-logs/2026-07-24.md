## 食材列表改用抽象名称

- 时间：2026-07-24
- 改动摘要：`ingredient_catalog` 列表和搜索结果统一显示 `canonical_name_zh`，具体形态名称保留为内部 `variantName`；同一食材概念存在多个可选形态时只展示一次并优先采用默认形态。营养素排行同样使用抽象名称，并按概念保留排名最高的形态。
- 原因：搜索和选择阶段应使用用户容易理解的食材概念名称，避免把生熟、部位或加工状态直接堆叠在列表主标题中；具体形态身份仍由 `variantId` 和 `foodId` 保留。
- 验证结果：定向测试 26/26、全量测试 164/164 通过；`npm run check:ui`、`npm run check:main-package` 和 `git diff --check` 通过。
