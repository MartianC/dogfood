**状态：** 已确认（D1.2 / D1.3 完成）

**日期：** 2026-08-01

**修订依据：** 用户明确否决首版重设计，要求“不改变当前页面设计，只做拆分；底部 TabBar 使用 D1.1 的设计”

**上游：** [`首页与全局导航设计交接`](./2026-08-01-home-and-global-navigation-design.md)、[`现状清单与导航迁移契约`](./2026-08-01-current-structure-and-navigation-migration-contract.md)

## 1. 修订裁决

本轮不再设计新的页面视觉，只对当前页面内容进行职责拆分：

- “狗狗”接走当前“我的”中的游客建档面板、狗狗档案标题、空态和狗狗列表；
- “我的”保留当前账号卡的头像、标题、说明和登录状态标签；
- 当前卡片、头像、字号、间距、圆角、按钮、空态和文案风格保持不变；
- 不新增状态标签、设置菜单、单狗概览页面或新的返回流程；
- 狗狗卡继续使用当前“修改”入口进入既有档案编辑页；
- 当前记录页的月历、加载、失败、空态、记录行、详情和返回行为全部保持不变；
- 一级页面底部统一替换为已完成的 `D1.1` TabBar；任务型详情页继续不显示 TabBar。

本修订取代同一 Figma Page 和同一交接文件的首版内容。后续 `F1.1`、`F1.2`、`F1.5` 不得引用首版中新增的单狗概览、状态卡或设置菜单。

## 3. D1.2 当前“我的”拆分

### 3.1 内容块迁移

| 当前 `pages/profile/index/index.wxml` 内容 | 目标页面 | 处理方式 |
| --- | --- | --- |
| 顶部 `ui-card > .profile-card` 账号卡 | 我的 | 原结构、样式和状态标签保留；不读取狗狗列表用于页面主体 |
| `.guest-panel` 游客建档面板 | 狗狗 | 整块迁移，继续使用当前标题、说明和登录建档按钮 |
| `.section-head`“狗狗档案 / 新增” | 狗狗 | 原样迁移 |
| `.profile-dog-list` 与 `.dog-panel` | 狗狗 | 原样迁移；头像、摘要和“修改”入口不重排 |
| `empty-state` 无档案状态 | 狗狗 | 原样迁移 |

### 3.2 保持不变的视觉合同

- 账号卡继续使用当前 `ui-card`、`96rpx` 方形头像、主副文字和右侧 `ui-tag`；
- 狗狗列表继续使用当前 `ui-card`、`88rpx` 方形头像、名字/修改同排和一行档案摘要；
- 游客建档面板继续使用当前卡片内标题、说明和整宽 `ui-button`；
- 无档案继续使用当前 `empty-state → ui-empty` 组合；
- 页面仍使用现有 `--df-*` token 和 UI Kernel，不增加组件或变体。

### 3.3 行为保持

```text
狗狗 / 新增、无档案动作、游客登录建档
  → 继续进入现有 dog-edit 任务页

狗狗 / 某只狗的“修改”
  → 继续进入现有 dog-edit?id=… 任务页
```

目标信息架构原先提到“单狗概览”，但本轮用户明确要求只拆分当前页面，因此 D1.2 不创建新的单狗概览设计或页面。若未来仍需要单狗概览，必须另行设计和确认，不能在 `F1.1` 中自行补做。

### 3.4 “我的”边界

“我的”本轮只保留当前账号卡，不新增隐私、帮助、反馈、设置或退出菜单。后续只能接入已经真实存在且另有明确设计依据的入口；不得以完成页面密度为由添加占位项。

## 4. D1.3 当前记录页原样保留

### 4.1 不改内容

以下视觉和文案直接沿用当前 `pages/records/index` 与既有 Figma L01–L06 / R01–R04：

- 页面标题“本餐记录”；
- 月份切换、日期选择和“已记”标记；
- 月份加载中、加载失败和“重新加载”；
- 整月空态及“记录第一顿”；
- 当天空态；
- 记录行的时间、狗狗、人饭菜单和食材数量；
- 本餐详情的保存快照结构、警示和返回行为。

`F1.5` 不得借 D1.3 修改以上内容、文案、卡片或详情布局。

### 4.2 唯一视觉替换

一级记录页移除当前旧三项 TabBar，直接换入 D1.1：

| 项目 | D1.1 规格 |
| --- | --- |
| 导航外框 | 375pt 画板使用 `343 × 64pt`，`x=16`、`y=720` |
| 中央动作 | `48 × 48pt` Fab，中心位于导航上方，标签“记一顿” |
| 目的地 | 首页、记录、狗狗、我的 |
| 记录页选中态 | “记录”使用主绿前景和浅绿背景 |
| 底部安全区 | 28pt |

本餐详情属于任务型子页面，继续保持当前 R01–R04 的无 TabBar 结构。
