# 狗饭微信小程序基础功能

## 当前主线：和狗狗一起吃

- 微信登录，并创建、编辑多个狗狗档案。
- 在狗狗档案中从食材目录选择确认的过敏食材；目标狗狗的过敏食材统一按 `blocked` 处理。
- 从首页为本次用餐选择一只狗狗；单狗可自动继续，多狗需要明确选择。
- 仅为档案完整、满 8 周，且没有疾病、妊娠、哺乳或治疗性体重管理需求的狗狗建立本餐。
- 从已经决定的人饭菜单中搜索并选择一道或多道已发布菜谱；产品不替用户规划或推荐人饭。
- 按菜查看全部来源原料及可共用状态：目录策略或目标狗狗过敏规则得到的 `blocked` 食材进入“狗狗不能吃”，展示原因且不可加入；其他非 `blocked` 食材可以加入狗饭，未映射原料只保留来源文字。
- 自动带入可共用基础食材，并允许用户移除或重新加入来源食材；狗饭始终需要单独称量、单独无调味烹饪。
- 计算本餐能量目标，但不自动生成任何食材的首次克重或比例；首次克重由用户逐项填写。
- 用户填写克重后，可主动预览并确认按能量目标等比例调整整餐。
- 食材或克重变化后，实时更新能量与营养密度双轴评估；营养偏低时可继续使用既有富含营养素食材入口调整本餐。
- 草稿支持恢复；发现已有草稿时，由用户明确选择继续编辑或重新开始。
- 保存一条幂等、可追溯的本餐记录；记录保留狗狗、人饭、狗饭、评估和数据版本快照。
- 记录页按月份和日期查看本餐记录，详情展示保存时的完整快照，不使用当前数据重新计算历史结论。
- 主导航为“首页、记录、狗狗、我的”，中央“记一顿”是常驻主操作，不是第五个 Tab。

首页回答今天接下来做什么，记录负责本餐历史回看，狗狗负责狗狗档案，“我的”只承载账号与低频设置能力；首页、记录空态和中央“记一顿”复用同一个入口服务。

## 产品边界

- 保存表示记录这一餐，不代表本餐营养完整或适合长期重复喂养。
- 首版只评估单餐，不提供连续多餐趋势、长期完整性判断或治疗性饮食方案。
- 首版不支持自定义人饭录入，不自动补充食材、营养补充剂或长期配方。
- 照片选择、上传、保存和详情展示不在当前范围内。

## 历史兼容功能

旧公共狗饭食谱、制作周期、批量采购与制作清单、多狗共同制作、清单导出和分享等页面及历史数据暂时保留兼容读取，但不再属于当前主导航和产品主流程，也不作为当前功能承诺。

当前产品范围和行为以 [`每日“和狗狗一起吃”单餐创建与记录 PRD`](./superpowers/specs/2026-07-26-shared-meal-checkin-prd.md) 为准。
